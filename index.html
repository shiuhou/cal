① 極座標曲線 CW7
考點核心極座標：轉換、切線、面積、弧長
核心概念
極座標用「距原點距離 \(r\)」和「方向角 \(\theta\)」描述點，取代直角座標的 \((x,y)\)。心形線、玫瑰線等曲線在極座標下方程極簡單。考試四大題型:座標/方程轉換、切線斜率、面積、弧長。每一種都有固定公式，關鍵是認出題目要哪一種。
信號 → 方法
見到咩用咩方法
極方程 → 直角:含 \(r\cos\theta\)、\(r\sin\theta\)、\(r^2\)→ 乘 \(r\) 或乘分母，代 \(x=r\cos\theta,\ y=r\sin\theta,\ r^2=x^2+y^2\)
直角 → 極:含 \(x^2+y^2\)、\(y/x\)→ 代 \(r^2=x^2+y^2,\ \tan\theta=y/x\)
求某點切線斜率→ \(dy/dx\) 極座標公式
求單條曲線圍成面積→ \(A=\frac12\int r^2\,d\theta\)
求兩曲線之間面積→ 先找交點，\(A=\frac12\int(r_{外}^2-r_{內}^2)\,d\theta\)
求曲線弧長 / 周長→ \(L=\int\sqrt{r^2+(r')^2}\,d\theta\)
判斷對稱性→ 代 \((r,-\theta)\)、\((-r,\theta)\)、\((-r,-\theta)\) 驗證
求垂直漸近線(如 \(r=a+b\sec\theta\))→ 算 \(x=r\cos\theta\)，取 \(r\to\infty\) 的極限
核心公式
座標轉換
\[x=r\cos\theta,\quad y=r\sin\theta\] \[r^2=x^2+y^2,\quad \tan\theta=\tfrac{y}{x}\]
切線斜率
\[\frac{dy}{dx}=\frac{r'\sin\theta+r\cos\theta}{r'\cos\theta-r\sin\theta}\]
面積
\[A=\frac12\int_\alpha^\beta r^2\,d\theta\] \[A_{between}=\frac12\int_\alpha^\beta(r_{外}^2-r_{內}^2)\,d\theta\]
弧長
\[L=\int_\alpha^\beta\sqrt{r^2+\left(\tfrac{dr}{d\theta}\right)^2}\,d\theta\]
決策流程
看到極座標題 │ ├ 要轉換方程? → 極→直角:乘 r/乘分母; 直角→極:代換 ├ 要切線? → 套 dy/dx 公式，代入 θ 值 ├ 要面積? → 單條:½∫r²dθ; 兩條:先找交點 → ½∫(r外²-r內²)dθ └ 要弧長? → √(r²+r'²) 積分，注意 θ 範圍讓曲線恰好走一遍
細節陷阱
  • 面積忘了 ½ — 是 \(A=\frac12\int r^2d\theta\)，不是 \(\int r^2d\theta\)
  • 兩曲線面積寫成 \((r_1-r_2)^2\) — 正確是 \(r_1^2-r_2^2\)，兩者差一個交叉項
  • 找交點漏了原點 — 兩曲線都過原點但 θ 不同，解 \(r_1=r_2\) 找不到，要單獨檢查 \(r=0\)
  • 弧長公式多加了 1 — 極座標弧長是 \(\sqrt{r^2+(r')^2}\)，沒有 \(1+\)(那是直角座標 \(y=f(x)\) 的公式)
  • arctan 象限錯誤 — \(\tan\theta=y/x\) 只給第一、四象限，要根據 \((x,y)\) 符號手動調整
  • 弧長積分區間讓曲線走超過一遍 — 確認 θ 範圍讓曲線恰好走一遍，否則弧長算多

② 數列與無窮級數 CW8
考點核心數列極限、遞推數列、能直接求和的級數
核心概念
這章兩條主線:(1) 數列極限 — 當 \(n\to\infty\) 時 \(a_n\) 趨向什麼;(2) 無窮級數 — 級數收斂 \(\iff\) 部分和數列 \(\{s_n\}\) 的極限存在。CW8 只處理能直接算出和的兩種級數(幾何、望遠鏡)，以及第 \(n\) 項測試(只能證發散)。複雜的收斂測試留到 CW10。
信號 → 方法
見到咩用咩方法
數列:多項式比多項式→ 上下同除最高次
數列:含 \(\sin n,\cos n\)→ 夾擠定理(\(-1\le\sin/\cos\le1\))
數列:\(\left(1+\frac{a}{n}\right)^n\) 形式→ 套 \(e^a\) 公式
數列:\(\sqrt{n^2+an}-n\) 型→ 有理化(乘共軛)
遞推 \(a_{n+1}=f(a_n)\)→ 設 \(L=f(L)\) 解方程，捨不合理根
級數:每項之比是定值 \(r\)→ 幾何級數 \(\frac{a}{1-r}\)
級數:通項可拆成 \(b_k-b_{k+1}\)→ 望遠鏡(部分分式)
級數:\(\lim a_n\ne0\) 或不存在→ 第 \(n\) 項測試 → 直接發散
核心公式
5 個必背數列極限
\[\lim_{n\to\infty}\frac{\ln n}{n}=0,\qquad \lim_{n\to\infty}\sqrt[n]{n}=1,\qquad \lim_{n\to\infty}a^n=0\ (|a|<1)\] \[\lim_{n\to\infty}\left(1+\frac{a}{n}\right)^n=e^a,\qquad \lim_{n\to\infty}\frac{a^n}{n!}=0\]
幾何級數
\[\sum_{k=0}^{\infty}ar^k=\frac{a}{1-r},\quad |r|<1\]
望遠鏡級數
\[\sum_{k=1}^{n}(b_k-b_{k+1})=b_1-b_{n+1}\]
增長速度(由慢到快)
\[\ln n\ \ll\ n^a\ \ll\ a^n\ \ll\ n!\ \ll\ n^n\qquad(a>1)\]
決策流程
【數列極限】 多項式比 → 除最高次 │ 有 sin/cos → 夾擠 (1+a/n)ⁿ → eᵃ 公式 │ 根式相減 → 有理化 遞推數列 → 設 L 解方程 【無窮級數】 Step 1: 第 n 項測試 — lim aₙ≠0? → 發散，停 Step 2: 等比形式? → 幾何級數公式 可拆相消? → 望遠鏡 (更複雜的收斂判斷 → 見 CW10)
細節陷阱
  • \(a_n\to0\) 就以為 \(\sum a_n\) 收斂 — 諧波級數 \(\sum\frac1n\) 是最重要反例:每項趨 0 但發散！第 \(n\) 項測試只能證發散
  • 遞推數列解方程後兩個根都寫 — 必須根據數列正負性捨去不合理的根
  • 幾何級數忘記檢查 \(|r|<1\) — \(|r|\ge1\) 時發散，公式不適用
  • \(e^a\) 公式記錯 — 是 \(\left(1+\frac{a}{n}\right)^n\to e^a\)，指數和分母的 \(n\) 要對應

③ 數列極限技巧 CW8
考點核心數列極限：見到咩 → 用咩方法速查
核心概念
數列極限常見技巧：多項式比多項式用除最高次；含根式相減用有理化（乘共軛）；含 \(\left(1+\frac{a}{n}\right)^{bn}\) 用 \(e^{ab}\) 公式；含 \(\sin n,\cos n\) 用夾擠定理；指數型先取 \(\ln\) 再處理。認出題目形式是第一步。
核心公式速查
有理化
\[\sqrt{n^2+an}-n=\frac{an}{\sqrt{n^2+an}+n}\to\frac{a}{2}\]
e 定義
\[\left(1+\frac{a}{n}\right)^{bn}\to e^{ab}\]
夾擠
\[-1\le\sin n,\cos n\le1\implies\frac{\sin n}{n}\to0\]
增長速度
\[\ln n\ll n^a\ll a^n\ll n!\ll n^n\quad(a>1)\]
決策流程
看到數列極限題 ├ 多項式比多項式? → 上下同除最高次 ├ 含 √(n²+an)-n? → 有理化（乘共軛） ├ 含 (1+a/n)^(bn)? → e^(ab) 公式 ├ 含 sin/cos? → 夾擠定理 ├ 指數/冪次型 aₙ^(bₙ)? → 取 ln，化成 bₙ·ln(aₙ) └ 含 ln n, n!, aⁿ? → 增長速度比較
細節陷阱
  • \(\left(\frac{2^n+3^n}{3^n-2^n}\right)\) 不會處理 — 除以最大項 \(3^n\)，得 \(\frac{1+(2/3)^n}{1-(2/3)^n}\to1\)
  • \(n^{3/(n-1)}\) 忘記取 ln — 取 \(\ln\)：\(\frac{3}{n-1}\ln n\to0\)，故極限為 \(e^0=1\)
  • \(\ln(1+3^n)/\ln(1+2^n)\) 近似錯誤 — 大 \(n\) 時 \(\ln(1+a^n)\approx n\ln a\)，答案為 \(\ln3/\ln2\)

④ 收斂性測試 CW10
考點核心正項級數六大測試 + 交替級數
核心概念
考試最高頻題型:給你一個級數，判斷收斂/發散。關鍵不是每個方法都會，而是「看一眼就知道用哪個測試」。每個測試有固定的「觸發信號」，養成條件反射。
信號 → 方法
見到咩用咩
\(\lim a_n\ne0\) 或不存在→ 第 \(n\) 項測試 — 直接發散(第一步必查!)
直接是 \(\frac{1}{n^p}\) 形式→ p-series:\(p>1\) 收，\(p\le1\) 發
多項式比多項式、有根號的分式→ Limit Comparison — 找主導項配 p-series
能直接看出上界/下界(\(|\sin n|\le1\) 等)→ Direct Comparison
含 \(n!\) 或 \(a^n\)(指數與階乘)→ Ratio Test
整體是 \((\cdots)^n\) 形式→ Root Test
\(f(n)\) 正、連續、遞減且容易積分→ Integral Test
含 \((-1)^n\)，交替正負→ 先試絕對收斂(取絕對值用正項測試);不行再用 Leibniz Test
核心公式
p-series
\[\sum\frac{1}{n^p}:\quad p>1\ \text{收},\quad p\le1\ \text{發}\]
Ratio Test
\[\rho=\lim_{n\to\infty}\left|\frac{a_{n+1}}{a_n}\right|:\quad \rho<1\ \text{收},\ \rho>1\ \text{發},\ \rho=1\ \text{無結論}\]
Root Test
\[\rho=\lim_{n\to\infty}\sqrt[n]{|a_n|}:\quad \text{結論同 Ratio}\]
Limit Comparison
\[L=\lim\frac{a_n}{b_n}:\quad 0
Leibniz Test(交替級數)
\(\sum(-1)^{n-1}u_n\) 收斂，若:① \(u_n>0\) ② \(u_n\ge u_{n+1}\)(遞減) ③ \(\lim u_n=0\)
誤差估計:\(|S-s_n|\le u_{n+1}\)
絕對 vs 條件收斂
\(\sum|a_n|\) 收 → 絕對收斂；\(\sum|a_n|\) 發但 \(\sum a_n\) 收 → 條件收斂
決策流程
Step 1: lim aₙ ≠ 0? → 發散，停 Step 2: aₙ 長什麼樣? ├ 1/nᵖ → p-series ├ 多項式比/根號 → Limit Comparison (找主導項配 1/nᵖ) ├ 明顯上下界 → Direct Comparison ├ 含 n! 或 aⁿ → Ratio Test ├ 整體 (...)ⁿ → Root Test ├ f(n) 易積分 → Integral Test └ 含 (-1)ⁿ → 先試絕對收斂;否則 Leibniz
細節陷阱
  • Ratio/Root Test \(\rho=1\) 就下結論 — \(\rho=1\) 完全不確定！必須換方法。\(\sum1/n\) 和 \(\sum1/n^2\) 都給 \(\rho=1\)
  • 比較方向搞反 — 大收罩小:✓；小發逼大:✓；大發/小收推不出結論！
  • Limit Comparison \(L=0\) 或 \(L=\infty\) 套標準版 — 這兩個是單向結論，不能說「同收發」
  • Leibniz 只驗了 \(\lim u_n=0\) — 三個條件(正、遞減、趨零)缺一不可
  • \(2^{\ln n}\) 不會化簡 — \(a^{\ln n}=n^{\ln a}\)，所以 \(2^{\ln n}=n^{\ln 2}\)
